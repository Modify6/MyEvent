## 1. 产品概述

### 1.1 一句话定位

以「对象」为中心,记录外部事件与内部想法的**演化过程**;预判先锁定再验证,沉淀「如果 X,则 Y」的可复用经验规则。

### 1.2 解决的问题

1. 经历的事不能只变成流水账,要变成可回溯的过程与可复用的经验;
2. 对一个人、项目、标的的想法会变化,需要看见认知演化;
3. 预判需要被记录、锁定、验证,才知道自己的判断偏差在哪;
4. 下次遇到相似场景时,能调出历史经验与校准提示。

### 1.3 目标用户与边界

- **单用户、隐私优先、本地优先**:不联网一切可用,服务器只是可选同步增强;
- 不是社交产品,不是团队协作工具;
- 不是流水账日记(主入口是记录流与对象,不是"今日流水");
- 不是时间账本(与同作者 MyTime 分工:MyTime 管时间流向,MyEvent 管认知演化)。

### 1.4 产品原则(设计铁律,需求演进的结晶)

| # | 原则 | 来源 |
|---|---|---|
| P1 | **过程优先**:记录是主体,可持续、完整地看演化;总结是水到渠成的输出,不是一开始就奔着去的关卡 | v0.3.0 方向修正 |
| P2 | **三层模型**:记录(瞬间)→ 线索(过程)→ 对象(视角),判断口诀「对象=关于谁,线索=哪件事,想法=念头本身」 | v0.3.0 + 挂靠指南 |
| P3 | **可逆与留痕**:软删可恢复、修改存修订史、挂靠随时改、归类成本为零 | v0.3.1/0.3.2 |
| P4 | **防事后合理化**:预判先定标准再锁定,锁定后原始判断不可改 | 0.2.3 原始设计 |
| P5 | **防误用**:就地解释(色彩分层)、全局使用指南、口诀与推荐 | v0.3.5/0.4.0/0.4.3/0.4.5 |
| P6 | **无催促**:无待办徽标、无弹窗提醒;所有"提醒"均为被动展示 | v0.3.0 定调 |
| P7 | **数据自主**:本地优先、云端只是副本、导出自由、删改皆留痕 | v0.4.1 |

## 2. 概念模型与信息架构

### 2.1 三层概念模型

```
记录(原子)   「刚才发生了什么/我想到了什么」   一个瞬间,带时间戳与触发源
   ↓ 归入(可跳层、可裸记、随时改挂)
线索(过程)   「这件事的来龙去脉?推进到哪了?」 有始有终的一段故事
   ↓ 归入
对象(视角)   「我对它的判断怎么演化的?」      长期主体,没有终点
```

记忆法:**记录是砖,线索是用砖砌的一段墙,对象是整栋楼**。散放一块砖也没关系,以后随时砌回去。

### 2.2 信息架构(五大主入口)

| Tab | 路由 | 内容 |
|---|---|---|
| 记录 | `/` | 时间线记录流(首页):快捷记 + 全部记录按天混排 |
| 事件 | `/events` | 线索列表(按状态过滤) |
| 对象 | `/subjects` | 对象列表 |
| 经验 | `/rules` | 经验规则卡片库 |
| 回顾 | `/review` | 周/月概览、热力格、触发源统计、置信度校准 |

辅助页:搜索 `/search`、设置 `/settings`、回收站 `/trash`、对象详情、线索详情、预判详情(`/predictions`,按需入口,不进 tabbar)、账户模块(`/accounts`,MyAsset 移植,按需)。

### 2.3 领域数据模型(六表 + 账户模块)

| 表 | 内容 | 关键字段 |
|---|---|---|
| thoughts | 随手记录(想法/事实/感想/灵感/疑问/判断/决策/观察) | kind、source(触发源)、subjectId、relatedEventId、edits(修订史) |
| events | 线索 | title、fact、subjectIds[]、threadState、categoryId |
| eventEntries | 线索过程记录(含小结 kind='summary') | eventId、kind、triggerKind、triggerNote、edits |
| subjects | 对象 + 当前观点快照 | currentView、currentConfidence、topReasons、biggestRisk |
| predictions | 预判(锁定快照不可变) | status、criteria、origConfidence、result |
| rules | 经验规则 | content、scene、validity、verifyCount |
| accounts / snapshots | 资产模块(MyAsset 移植,按需) | balance 等 |

通用约定:全表 `id / createdAt / updatedAt(LWW 逻辑时钟) / deleted(软删) / serverRev(增量游标)`;数组/对象列经 JSON 列协议同步。

## 3. 功能需求

> 每个模块给出:用户故事 → 功能点 → 验收标准。标注 [P] 的为产品原则落地点。

### 3.1 记录流(首页,核心输入口)

**用户故事**:作为一个想随时捕捉想法的人,我希望 3 秒内记下一句话,并且以后能完整看到它的演化。

**功能点**:
- F1.1 快捷输入:仅内容即可发送;Enter 直接发送(桌面);发送后焦点保持,支持连续记录;
- F1.2 添加细节(全部可选):类型(8 种,专属色+图标)、触发源(8 种+说明)、挂到线索/挂到对象(**就地快速新建**并自动选中)、一键重挂上次挂靠组合;
- F1.3 时间线混排:随手记 + 线索过程记录 + 小结,按天分组倒序(今天/昨天/M月D日);
- F1.4 视觉分层:类型专属色+图标、触发源图标、`#线索`/`@对象` 分色可点跳转;小结高亮 + 左侧竖条;
- F1.5 二次处理:点击=修改、长按=操作菜单(编辑/删除/转为线索);修改存修订史并标记「已编辑」;
- F1.6 转为线索:想法长成事件时,长按菜单直达——起标题即建线索并自动改挂(挂靠对象继承);
- F1.7 筛选条:类型/对象/线索三路下拉;
- F1.8 分页:默认渲染最近 50 条,「还有 N 条 · 加载更多」。

**验收标准**:
- [P1] 只填内容点发送,记录立即出现在时间线顶部;
- [P3] 编辑过的记录显示「✎ 已编辑」,弹层内可查看每次修改前的原文与时间;
- [P2] 记录的挂靠 chips 点击直达线索/对象页,不触发编辑;
- 挂靠对象/线索可在添加细节与编辑弹层中就地新建(输入名称即建即选)。

### 3.2 事件线索(过程容器)

**用户故事**:作为跟进一件持续发展的事的人,我希望这件事的所有记录按时间连成一条完整过程线。

**功能点**:
- F2.1 新建线索:标题必填,其余全可选;可填触发源(自动成为首条过程记录);
- F2.2 过程时间线:过程记录 ∪ 挂靠的随手记,倒序;轨道化视觉(贯穿竖线 + 类型着色节点);过滤(全部/只看想法/只看小结);分页;
- F2.3 记一笔(过程中的一个点)与写小结(自由文本,可多次、随时补、高亮展示,无完成标准);
- F2.4 线索信息编辑:标题/事实/场景/挂靠对象建后可改;
- F2.5 软收尾:完结/搁置/重新打开——纯手动标记,列表按状态过滤(默认进行中),过程全保留;
- F2.6 导出 Markdown:完整时间线文档(状态/挂靠/触发源/小结);
- F2.7 二次修改:过程记录与小结可编辑(触发源/时间/内容),留痕同 F1.5。

**验收标准**:
- [P1] 小结不设格式与完成标准;写多写少、写不写均不影响任何流程;
- [P4] 无"待复盘"状态机、无强制「下次规则」;规则句式校验仅为引导不阻断;
- 删除线索为软删,可在回收站恢复。

### 3.3 对象中枢(认知演化)

**用户故事**:作为长期关注某些主体的人,我想一眼看到"我对它的判断从哪来、被什么改变、准不准"。

**功能点**:
- F3.1 对象列表:彩色首字头像(id 稳定取色)、类型彩签、统计行(线索/记录/预判数);
- F3.2 当前观点快照:核心判断 + 置信度 + 核心理由 + 最大反证 + 开放问题 + 下次回顾日期;
- F3.3 观点草稿:纯本地拼接最近 8 条记录为草稿供改写(非 AI);
- F3.4 观点老化温和提醒:超 30 天未更新且期间有新记录时被动提示(无徽标无催促);
- F3.5 三轨时间线:事实/想法/预判,轨道化 + 过滤(全部/事实/想法/预判) + 分页;
- F3.6 未验证假设聚合;关联经验规则聚合(点击直达经验库);
- F3.7 预判命中统计:hit + 0.5×partial,已验证数展示。

**验收标准**:
- [P6] 观点老化提醒纯被动展示;
- 同一对象在列表与详情使用同一头像色(id 散列稳定取色)。

### 3.4 预判(按需功能,不进 tabbar)

**用户故事**:作为想校准判断力的人,我希望预判先被"冻结",到期按当时的标准诚实评分。

**功能点**:
- F4.1 创建:可证伪内容 + 所属对象 + 验证窗口 + 置信度(50-100%)+ 验证标准(命中/部分/错误);
- F4.2 锁定:内容/窗口/置信度/标准写入不可变快照;进行中上限 15 条;
- F4.3 验证:按提交时的标准评分(命中/部分/错误/无法验证)+ 偏差原因多选 + 链路最弱环节 + 事后信息分离;
- F4.4 入口:对象页「做预判」与回顾页校准区(撤出 tabbar,按需使用);
- F4.5 校准统计:置信度分桶命中率(含完美校准参考线)、按类型命中率(回顾页)。

**验收标准**:
- [P4] 锁定后核心字段不可改,验证评分须对照提交时定义的标准;
- 校准统计只服务自我认知,不排名不制造焦虑。

### 3.5 经验库

**用户故事**:作为希望不再重复犯错的人,我想把教训沉淀成可执行的规则,并在下次实际用到时验证它。

**功能点**:
- F5.1 规则卡片:内容(推荐「如果 X,则 Y」句式,不强制)、适用场景、触发信号、背后原因、反例;
- F5.2 来源:事件复盘 / 预判验证 / 手动创建,均记录来源引用;
- F5.3 有效性登记:实际使用后点「这次有效/无效」,累计验证次数;
- F5.4 说明:规则句式校验仅为引导提示(不阻断保存)。

### 3.6 回顾

**用户故事**:作为想看见自己记录节奏与判断质量的人,我想在回顾页看到周期性的自我画像。

**功能点**:
- F6.1 周/月切换:概览(新事件/想法/预判/已复盘)、动态清单(点击直达)、月视图含与上月环比;
- F6.2 12 周热力格:每周一格深浅=记录数,点某周跳转该周明细;
- F6.3 触发源分布:本周(月)什么最容易引发记录,占比条;
- F6.4 高频场景;置信度分桶校准(含完美校准参考线);按类型命中率。

**验收标准**:
- [P6] 统计只服务自我认知,不排名不制造焦虑;
- 热力格与周/月明细联动(点某周 → 周视图与数字切换)。

### 3.7 搜索

- 覆盖六类内容:对象 / 事件(线索) / 想法 / 过程记录(含小结) / 预判 / 规则;
- 结果直达所属页面(想法→所在线索/对象,事件→线索详情);空态说明覆盖范围。

### 3.8 设置与数据

- 多设备同步(可选):单密码鉴权、outbox 队列、LWW 合并、增量游标、写后防抖上推、云端每日快照;连接语义就地说明(云端只是副本);
- 导出/导入 JSON(按修改时间合并,不覆盖新数据);服务器快照备份;
- 回收站:软删记录查看与恢复(不做彻底销毁);[P3][P7]
- 运行日志、使用指南(9 核心概念总表)、版本迭代史。

### 3.9 使用指南与防误用

- 全局使用指南(设置页入口):9 核心概念总表 + 记忆法;
- 行内提示四级色彩分层:🔵概念类 / ⚪操作类 / 🟢安全类 / 🟡警示类;
- 一行多概念解释采用 seg-explain 分段着色(术语与实际元素同色);
- 弹层 chips 与时间线标签同色系(选什么颜色 = 显示什么颜色);
- 挂靠指南:口诀 + 三类对照 + 演化路径 + 判断信号(同一件事的念头反复出现 → 转线索)。

## 7. 路线图

### 已完成
P0 全量(0.2.x)→ 过程记录驱动重构(0.3.x)→ 防误用与视觉体系(0.4.0-0.4.5)→ 数据安全与质量(0.4.1)→ 可视化四件套(0.4.7)。

### P1(候选,按真实使用摩擦排序)
1. **图片附件**:记录挂照片/截图(需设计压缩与同步策略,单独立项);
2. **想法修正链**:同一对象的判断变化自动串联(A→B→C 修正视图);
3. **盲测模式**:预判前隐藏历史观点,防锚定;
4. **月度对比增强**:回顾页月视图扩展(结构对比/趋势折线)。

### P2(远期)

## 8. 成功指标(衡量产品是否有效)

5. 规则复用:规则被标记「有效」的比例;
6. 修订留痕使用率:编辑行为占比(过程主义的直接体现);
7. 主观指标:能否更快调出历史经验(搜索命中 → 后续行为)。
